# API contract reference

`openapi.json` is an unmodified snapshot of the public TRYDOKU OpenAPI 3.1.0 specification fetched on **2026-10-04** from:

[https://www.trydoku.com/docs/api/api.json](https://www.trydoku.com/docs/api/api.json)

The specification declares `https://www.trydoku.com/api/v1` as its server. It is generated by Scramble from the Laravel application's routes, controllers, requests, and resources. The interactive reference is available at [TRYDOKU API reference](https://www.trydoku.com/docs/api/reference).

To refresh the snapshot:

```sh
curl --fail --silent --show-error --location \
  https://www.trydoku.com/docs/api/api.json \
  --output docs/api/openapi.json
```

The snapshot includes three customer API operations and the inbound Paddle billing webhook. The webhook is called by Paddle and is not a customer SDK operation.

Read [coverage.md](coverage.md) for the verified SDK scope, response details, and differences between the generated schema and runtime code.
